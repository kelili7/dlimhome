# DLIM Home 双语品牌网站

## 项目概述

1. DLIM Home 双语品牌网站。网站以陶瓷及家居产品为核心，介绍品牌、产品系列、制作流程与服务支持，并提供业务咨询和招聘信息入口。
2. 项目采用前后端分离架构：Vue 3 负责官网页面，Django 提供管理后台与 API。官网支持中英文切换。

## 网站结构

1. 首页：品牌主视觉、精选产品、陶瓷工艺介绍、产品轮播、品牌理念、常见问题与生活指南。
2. 产品：产品系列展示，支持品类筛选、关键词搜索和筛选重置。
3. 工厂：介绍陶瓷产品开发流程、品质关注点与系列定制。
4. 关于我们：品牌背景、理念、业务布局与市场连接示意。
5. 服务支持：选购、产品养护、订单服务及商业合作指南。
6. 业务咨询：整理零售、批量采购及定制合作需求。
7. 加入我们：介绍团队、员工福利、招聘流程与简历投递方式。
8. 产品系列详情：展示产品系列介绍、图片、特点及相关咨询入口。
9. 其他页面：自定义 404 页面。

## 主要功能

1. 中英文界面及内容切换，并记住访客的语言选择。
2. 产品分类筛选、关键词搜索和空结果提示。
3. 首页双列图片滚动、产品轮播、FAQ 展开与返回顶部。
4. 页面内容与图片的滚动入场效果、路由切换动画，以及系统“减少动态效果”偏好支持。
5. 业务咨询表单校验，并生成可复制或下载的本地咨询摘要。该表单只在当前页面生成摘要，不会向后台提交、保存或自动发送信息。
6. 招聘页面通过邮件客户端发起简历投递，网站本身不直接收集或发送简历。
7. 当前网站为静态网站，后端业务待开发。

## 技术栈

1. 前端：Vue 3、Vue Router、Vite、GSAP
2. 后端：Django、Django REST Framework、django-simpleui
3. 开发数据库：SQLite
4. 部署：GitHub Actions、GitHub Pages
